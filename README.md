## 📌 ABOUT THE PROJECT

Movie Listing App is a front-end web development project that provides a simple and user-friendly interface for browsing movie listings.

Built using HTML, CSS, and vanilla JavaScript, the application demonstrates the fundamentals of web development, including webpage structuring, styling, and interactive functionality.

📌 About The Project

The Movie Listing App is a front-end web development project designed to demonstrate the fundamentals of modern web development using HTML, CSS, and vanilla JavaScript.

The application focuses on creating an engaging movie browsing experience with a responsive interface and interactive elements.

It is developed as a practical project to improve front-end development skills and understand how HTML, CSS, and JavaScript work together to build interactive web applications.
