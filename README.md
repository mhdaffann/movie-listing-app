#🎬 Movie Listing App

A simple and interactive Movie Listing Web Application built using HTML, CSS, and JavaScript. This project provides a user-friendly interface for exploring and browsing movie listings with a clean and visually appealing design.

🌐 Live Demo: "Movie Listing App" (https://mhdaffann.github.io/movie-listing-app/)

---

📌 About The Project

The Movie Listing App is a front-end web development project designed to demonstrate the fundamentals of modern web development using HTML, CSS, and vanilla JavaScript.

The application focuses on creating an engaging movie browsing experience with a responsive interface and interactive elements.

It is developed as a practical project to improve front-end development skills and understand how HTML, CSS, and JavaScript work together to build interactive web applications.

---

✨ Features

- 🎥 Movie Listings – Browse movies through an organized listing interface.
- 🎨 Modern UI Design – Clean and visually appealing user interface.
- 📱 Responsive Design – Designed to provide a consistent experience across different screen sizes.
- ⚡ Interactive Elements – JavaScript-powered interactions for a dynamic browsing experience.
- 🌐 Web-Based Application – Accessible directly through a web browser.
- 🚀 GitHub Pages Hosting – Deployed and accessible online.
